# Footer

## Purpose
Provides a simple footer for the application shell.

## Props
This component has no props.

## Example usage
```tsx
import { Footer } from '@/components'

<AppLayout footer={<Footer />}>...</AppLayout>
```

## Styling notes
Uses `styles.module.css` for layout and muted typography.

## Admin configuration
Footer copy should be sourced from WordPress or site settings when available.
