# HelpSuccessSection

## Purpose
Presents a focused strategic positioning statement in a prominent supporting section.

## Props
- `title`: Section heading.
- `text`: Supporting paragraph copy.

## Example usage
```tsx
import { HelpSuccessSection } from '@/components'

<HelpSuccessSection
  title="How we help you succeed"
  text="A concise strategic message that supports the homepage story."
/>
```

## Styling notes
Uses a single panel layout with theme-based surface, border, and typography styling.

## Admin configuration
Current usage is repo-controlled. The title and text can be mapped to WordPress fields later if editorial control is needed.
